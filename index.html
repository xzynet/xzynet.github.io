INSTALL

搜索即可安装，听课记录一步到位

无需注册，无需配置。安装后打开网课视频，点击浏览器工具栏中的「学知云课记」图标，即可开始记录。

Chrome / Edge

Chrome 网上应用店安装

在 Chrome 应用商店打开扩展页面，点击「添加至 Chrome」即可，自动更新。

Edge 用户：Edge 可以直接安装 Chrome 商店的扩展。首次安装时点击浏览器顶部提示的「允许来自其他商店的扩展」，之后流程与 Chrome 完全一致。
前往 Chrome 应用商店

Firefox

Firefox 附加组件商店安装

在 Firefox Add-ons 打开扩展页面，点击「添加到 Firefox」，权限确认后即完成安装。

已针对 Firefox 完整适配（sidebarAction 侧边栏），转写模型为 Paraformer，功能与 Chrome 版保持一致。
前往 Firefox 附加组件

也可以直接在两个商店中搜索 「学知云课记」 或 XZY Notes，认准学知云官方发布。

FEATURES

不只记下画面，更留住知识的脉络

少切一次窗口，少拖一次进度条，把更多注意力留给学习。

截图就是笔记Alt+S

一键保存当前视频画面，支持圈画标注，重点内容无需暂停也能记录。

时间戳精准回跳

每条笔记都对应视频时刻，点击即可回到原位，重点段落还能 A-B 循环复读。

字幕全文检索

课程字幕变成可搜索的时间轴，找到那一句讲解，不再反复拖动进度条。

本地语音转写

没有字幕的课程，也能在浏览器本地转成文字，模型下载后可离线使用。

章节大纲整理

把冗长课程梳理成清晰章节，快速了解内容结构，复习更有方向。

Markdown 自由导出

截图、笔记、章节与时间戳一起导出，轻松带入 Obsidian、Notion 等工具。
